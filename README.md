# Somnolance-v1
### Installation

1. Téléchargez **Somnolence-V1.exe** ci-dessous. La DLL est intégrée ; aucun fichier source ni DLL séparée n’est nécessaire.
2. Ouvrez le lanceur, lancez BO3 via Steam ou ouvrez-le vous-même, puis attendez son menu principal.
3. Cliquez sur **Injecter Somnolence v1**. L’injection reste manuelle. **F5** ouvre et ferme l’interface.

### Cette version

- Interface en français et outils Zombies.
- Préparation du menu en jeu au salon, avant le lancement de la partie ; ouverture avec visée + couteau.

### État connu

Certaines cartes custom fonctionnent, mais la compatibilité avec certaines map reste a corrigé  
Après une mise à jour, redémarrez BO3 puis injectez manuellement la nouvelle version.
